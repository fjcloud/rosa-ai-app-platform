= AI Developer Platform on ROSA

Start with an *existing ROSA cluster* from Red Hat Demo Platform. RHDP prepares the cluster, bastion, AWS credentials, Red Hat login, and Marketplace billing.

== Run the workshop

. Order a ROSA workshop environment on https://demo.redhat.com[Red Hat Demo Platform], wait until it is ready, and assign participant access.
. Open https://fjcloud.github.io/cloud-terminal-pages/[Cloud Terminal], choose *AWS · AI developer platform on ROSA*, and enter the *workshop ID, assigned email, and workshop password*.
. The launcher retrieves the assigned Showroom URL. Shared workshop links contain only the guide and workshop ID; each participant signs in separately.
. Follow Act 0 to log in with `oc`, clone this repository, and run `bash scripts/onboard.sh`.

The platform labs require an existing ROSA HCP cluster, cluster-admin access, OpenShift 4.22 or later, and AWS GPU quota. Lab 1.1 detects the connected cluster and reuses its worker subnet to create one GPU node. The workshop adds the GPU pool, platform operators, model serving, and developer tooling; it does not create the base cluster.

== Content

Instruction pages are in `content/modules/ROOT/pages`; Kubernetes manifests are in `deploy`. The content builds with Antora and is published on https://fjcloud.github.io/rosa-ai-app-platform/modules/index.html[GitHub Pages].

Provisioning an independent cluster remains available through https://github.com/fjcloud/rosa-quickstart[rosa-quickstart], outside the participant onboarding flow. Do not run it in an assigned RHDP environment that already has a cluster.
