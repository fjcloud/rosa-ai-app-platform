= Showroom Repository for the Rosa Workshop

This repository holds the instructions for the ROSA Workshop.

Act 0 creates the ROSA hosted control plane cluster from an empty AWS account with https://github.com/fjcloud/rosa-quickstart[fjcloud/rosa-quickstart].

Instruction pages are in content/modules/ROOT/pages.

To be intended to be used with Red Hat Demo Platform Showroom but can be built using Antora as well.


== Browser onboarding

Open https://cloud-terminal.azurewebsites.net/[Cloud Terminal], choose *AWS*, then *rosa-ai-app-platform*. Use the workshop id (or catalog URL), email and password assigned by the facilitator. The shell is signed in to the AWS lab and Red Hat. Credentials are available in `~/.workshop-aws.env` and `~/.rhcs.env`; do not print or commit them.

Run `bash scripts/onboard.sh` after cloning this repository to check the tools and identities without creating a cluster. Act 0 explains how to reuse the Red Hat credentials in `rosa-quickstart/.env`. Removing an AWS terminal deletes its files. Red Hat credentials expire at midnight Europe/Paris; start again to refresh them.
