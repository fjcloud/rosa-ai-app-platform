Welcome to Act 2. You are now the *Developer* — first day on a platform that will not send your source to a public LLM. Everything you need — editor, terminal, OpenCode, Qwen3.8 on the cluster — is in the browser through *OpenShift Dev Spaces*. No laptop install.

== What is OpenShift Dev Spaces?

OpenShift Dev Spaces provides *cloud-based developer workspaces* — VS Code-compatible IDEs that run as pods in the cluster. Key benefits:

* *Zero local setup:* the workspace comes pre-configured; just open a browser
* *Consistent environment:* every developer gets the same tools, versions, and configuration
* *In-cluster access:* your workspace calls Models-as-a-Service at `https://maas.<apps-domain>/...` with the injected `sk-oai-` key — same OpenAI API, governed quota
* *Persistent storage:* your work is saved on a per-user PVC even if you close the browser

== Get the Dev Spaces URL

Your instructor has already prepared the launch URL for you.
It points at the platform template on GitHub and creates a workspace from its `devfile.yaml`:

[source,text,options=nowrap]
----
https://devspaces.apps.<cluster>/#https://github.com/fjcloud/go-app-template?ai-provider=opencodeai/opencode
----

[NOTE]
====
The `#<template-url>` suffix tells Dev Spaces to clone the template and create a workspace from its `devfile.yaml` automatically. OpenCode is injected by the platform (AI tool registry) and already talks to Qwen3.8. The workspace comes pre-loaded with `AGENTS.md`, `pipeline/`, `gitops/`, and `deploy/base/` — you only need to write the application code.
====

. Open the URL your instructor shared in your browser.

== Verify OpenCode is Running

. Open a terminal in the workspace (*Terminal → New Terminal* or press kbd:[Ctrl+`]).

. Check that OpenCode is on `PATH` (injected) and that ephemeral Git is configured (`$GIT_SERVER`):
+
[source,sh,role=execute]
----
opencode --version && echo "GIT_SERVER=$GIT_SERVER"
----
+
.Sample Output
[source,text,options=nowrap]
----
opencode 0.x.x
GIT_SERVER=https://git.<workshop-domain>
----

. Verify OpenCode can reach Models-as-a-Service. Look up the MaaS Gateway hostname (this is a Gateway API front door, not a cluster Ingress domain and not an OpenShift `Route`):
+
[source,sh,role=execute]
----
MAAS_HOST=$(oc get gateway maas-default-gateway -n openshift-ingress \
  -o jsonpath='{.spec.listeners[0].hostname}')

curl -sS "https://${MAAS_HOST}/v1/models" \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  | python3 -m json.tool
----
+
.Expected Output
[source,json,options=nowrap]
----
{
  "object": "list",
  "data": [
    {
      "id": "publishers/llm-serving/models/qwen3",
      "owned_by": "llm-serving/qwen3",
      "ready": true,
      "modelDetails": {
        "displayName": "Qwen3.8",
        "contextWindow": "40960"
      }
    }
  ]
}
----
+
[TIP]
====
`$OPENAI_API_KEY` is the MaaS `sk-oai-` key the platform minted into Secret `ai-provider-openai-api-key`. `$OPENAI_BASE_URL` is the live MaaS path (`https://maas.<apps-domain>/llm-serving/qwen3/v1`) — `configure-platform.sh` binds the Gateway cert to this cluster, so the id in the secret name changes every ROSA cluster. OpenCode calls that URL so the API model id stays `qwen3`.
====

. Start OpenCode:
+
[source,sh,role=execute]
----
opencode
----
+
The OpenCode TUI (Terminal UI) launches. It reads `AGENTS.md` and connects to the Qwen3.8 LLM automatically.
Two built-in session modes are available via `/plan` and `/build` slash commands.
Press `q` to exit OpenCode when needed.

== Understanding the OpenCode Configuration

OpenCode reads **project** `opencode.json` first (it overrides the platform mount under `~/.config/opencode`). Verify the file in the template:

[source,sh,role=execute]
----
cat ${PROJECT_SOURCE}/opencode.json
----

Expected content:

[source,json]
----
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "qwen3": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Qwen3.8",
      "options": {
        "baseURL": "{env:OPENAI_BASE_URL}",
        "apiKey": "{env:OPENAI_API_KEY}",
        "chunkTimeout": 120000,
        "timeout": 600000
      },
      "models": {
        "qwen3": {
          "name": "Qwen3.8",
          "limit": {
            "context": 40960,
            "output": 8192
          }
        }
      }
    }
  },
  "model": "qwen3/qwen3",
  "autoupdate": false
}
----

OpenCode still reads `AGENTS.md` from the project directory at the start of every session. That is how the Platform Engineer's rules are enforced.

If `opencode.json` still mentions `qwen36` or `llm-inference`, this workspace cloned an old template. Run `git pull origin main` (or create a new Dev Space).

`limit.output` must stay well below `--max-model-len` (40960). OpenCode's default 32 000 output tokens would overflow the vLLM context window.
