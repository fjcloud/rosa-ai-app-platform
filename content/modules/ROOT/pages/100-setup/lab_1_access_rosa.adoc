= Act 0 — Get in

Clone this workshop repository, confirm `oc` is logged into a ROSA cluster, and confirm `rosa` works. All `oc apply -k deploy/...` commands in Act 1 run from this repo — not from the Go app template.

[NOTE]
====
*Estimated time:* 5 minutes
====

== Clone the workshop

This is https://github.com/fjcloud/rosa-ai-app-platform[`fjcloud/rosa-ai-app-platform`] — operators, instances, inference, and lab assets. Stay in this directory for Act 1.

[source,sh,role=execute]
----
git clone https://github.com/fjcloud/rosa-ai-app-platform.git
cd rosa-ai-app-platform
----

== Cluster and ROSA CLI

You must already be logged in to the cluster (`oc`). The `rosa` CLI must work.

[source,sh,role=execute]
----
oc whoami && oc get nodes
rosa whoami
----

You should see `cluster-admin` (or equivalent), two or three worker nodes, and a successful `rosa whoami`. *No GPU node yet* — that is Lab 1.1.

Console URL if you need the UI later:

[source,sh,role=execute]
----
oc whoami --show-console
----
